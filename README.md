# The Task — Atmospheric UI & Dandelion Visualizer

A polished, minimalist web application featuring an interactive abstract dandelion sunburst visualization with fluid gradient transitions across times of day.

## ✨ Features

- **Abstract Dandelion Sunburst**: 440+ fine radiating filaments ending in luminous dots, anchored at the bottom-center with organic breathing oscillation.
- **Dynamic Cursor Hover Interaction**: Filaments dynamically stretch and bend upwards toward the cursor on hover with spring physics.
- **6 Thematic Times of Day**:
  - **Daytime**: Crisp daylight sky blue with sun icon.
  - **Pre-dawn**: Soft lilac / lavender atmosphere with eye/dawn icon.
  - **Sunrise**: Warm golden-orange morning atmosphere with sunrise icon.
  - **Dusk**: Tranquil twilight purple palette with dusk icon.
  - **Sunset**: Vibrant peach/coral base dome with sunset icon.
  - **Night**: Deep cosmic indigo/midnight blue with crescent moon icon.
- **Minimalist Clean UI**: Centered framed layout with subtle divider accent line and top-right theme dropdown menu.
- **Full Video Flow Replay**: Includes built-in demonstration sequence to replay all atmospheric shifts automatically.

## 🚀 Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
